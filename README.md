# EC-BOX Poster Calendar – Advanced Prompting Techniques

## Project Overview

This project demonstrates how **advanced prompting techniques** can be used to create a 30-day B2B poster content calendar for an electrical company, **EC-BOX**.

### Prompting Techniques Learned

I learned the **RTCFR prompting framework**:

- **R – Role:** Define the AI's role.
- **T – Task:** Clearly explain what needs to be created.
- **C – Context:** Provide audience, business, and project information.
- **F – Few-Shot:** Provide examples or references.
- **R – Response:** Define the expected output format.

I also explored advanced prompting techniques:

**1. Reverse Prompting**  
Converted a normal prompt into a structured RTCFR prompt.

**2. Tree of Thought (ToT)**  
Expanded the RTCFR prompt into multiple decision paths for better topic selection, content planning, product relevance, and poster strategy.

**3. Sequential Chaining**  
Converted the ToT approach into a step-by-step workflow to generate a complete **30-day poster calendar**.
