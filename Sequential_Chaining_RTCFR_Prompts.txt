MASTER CHAINING INSTRUCTION

You are executing a 30-day sequential B2B content campaign for EC-BOX.

IMPORTANT:
This is NOT 30 independent poster ideas.

Each day's output must be influenced by:
1. The original EC-BOX RTCFR strategy.
2. EC-BOX website/blog/product references.
3. The previous day's topic and content.
4. The overall monthly content journey.
5. The target B2B audience.
6. The visual language established in previous posters.

SEQUENTIAL RULE:

Day N must review the output from Day N-1 before creating Day N.

Use the previous day's output to:
- Avoid repeating the same topic.
- Avoid repeating the same hook style unnecessarily.
- Avoid repeating the same CTA.
- Avoid repeating the same visual composition.
- Identify a logical next topic.
- Build deeper technical understanding.
- Connect the previous topic to the next customer problem.
- Progress the audience through Awareness → Consideration → Decision.

Do NOT copy the previous day's content.

Instead:
PREVIOUS TOPIC → IDENTIFY NEXT LOGICAL QUESTION → CREATE NEXT POSTER.

Example:

Day 1:
"What is IP Rating?"

Day 2:
"If IP protects against ingress, what protects against impact?"

Day 3:
"Now that we understand IP + IK, how do we select enclosure size?"

Day 4:
"Once size is selected, what enclosure construction should we consider?"

This creates a content chain rather than random posts.
